# evidence_pdf_splitter

按人工给定的证据清单，把一份完整案卷 PDF 切分为独立证据文件，并生成可直接编辑的证据目录表（Excel + Markdown）。

面向律师、法务与案卷整理人员。解决的是同一件重复劳动：一次庭审的卷宗往往两三百页，举证时需要按证据逐份拆分、按"证据名称 + 页码范围"命名、再誊一份目录——手工做一次两三个小时，且页码换算和漏页几乎必然出错。

## 设计原则：人定边界，脚本做机械劳动

这个工具**不判断证据边界**。哪些页属于哪份证据，是阅卷后的专业判断，交由使用者以清单形式给出。脚本只承担四件确定性工作：

1. 按页码范围从源 PDF 抽取页面；
2. 把卷宗印刷页码换算为 PDF 物理页序；
3. 按规范命名并输出独立文件；
4. 生成目录表并校验完整性（重叠、倒序、越界、重号、漏页）。

因此它不依赖 OCR、不做文字识别、不调用任何模型接口，输出结果可复现、可逐条核对。

## 适用与不适用

| | 说明 |
|---|---|
| 适用 | 已有完整卷宗 PDF；证据边界可由人工阅卷确定；需要按证据拆分提交或电子阅卷 |
| 不适用 | 需要从扫描件中自动识别证据标题（本工具不做 OCR）；需要判断证据的证明力或取舍 |

## 安装

要求 Python 3.10 及以上。

```bash
pip install -r requirements.txt
```

依赖仅两项：`pypdf`、`openpyxl`。

## 快速开始

```bash
# 1. 预演：只校验不写文件，先确认页码范围没填错
python evidence_pdf_splitter.py -p 卷宗.pdf -l 证据清单.xlsx --offset 2 --dry-run

# 2. 正式执行
python evidence_pdf_splitter.py -p 卷宗.pdf -l 证据清单.xlsx -o 输出 --offset 2

# 3. 用仓库自带的虚构样例试跑
python evidence_pdf_splitter.py -p samples/样例卷宗_虚构.pdf -l samples/样例证据清单.xlsx -o output --offset 2
```

样例卷宗为 20 页：前 2 页是封面与目录（无卷宗页码），正文为卷宗第 1–18 页，故 `--offset 2`。

## 命令行参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `-p, --pdf` | 源案卷 PDF 路径，只读打开 | 必填 |
| `-l, --evidence-list` | 证据清单，支持 `.xlsx` / `.xlsm` / `.csv` | 必填 |
| `-o, --out` | 输出目录 | `./output` |
| `--mode` | `split` 仅切分；`merged` 仅合并加书签；`both` 两者都出 | `both` |
| `--offset` | 固定偏移：物理页 = 卷宗页 + offset | `0` |
| `--map-file` | 锚点表 CSV，用于分段偏移；优先于 `--offset` | 无 |
| `--sheet` | Excel 工作表名 | 第一个工作表 |
| `--title` | 目录标题（如案件名称），写入 Excel 首行与 Markdown 标题 | 无 |
| `--page-label` | 文件名页码前缀：`auto` / `vol` / `pdf` | `auto` |
| `--allow-overlap` | 页码重叠降级为警告，不中断 | 关闭 |
| `--strict` | 警告也视为失败（退出码 1） | 关闭 |
| `--dry-run` | 只校验并打印将要生成的文件，不写盘 | 关闭 |
| `--version` | 打印版本号 | — |

`--page-label auto` 的规则：存在页码偏移时文件名标 `卷宗p`，无偏移时标 `PDFp`，避免把物理页序误标为卷宗页码。

## 清单字段

第一张工作表（或 `--sheet` 指定的表）第 1 行为表头，脚本在前 20 行内自动定位表头。列的顺序不限，多余的列会被忽略。

| 字段 | 是否必填 | 可识别的列名 |
|---|---|---|
| 证据编号 | 必填 | 证据编号、编号、证据序号、证据号、eid、no、id |
| 证据名称 | 必填 | 证据名称、名称、证据、name、title |
| 起始页 | 必填 | 起始页、起页、开始页、首页、起始页码、start |
| 结束页 | 选填 | 结束页、止页、终止页、末页、结束页码、end |
| 证据来源 | 选填 | 证据来源、来源、source |
| 证明目的 | 选填 | 证明目的、证明对象、证明内容、purpose |
| 原件/复印件 | 选填 | 原件/复印件、原件或复印件、形式、form |
| 备注 | 选填 | 备注、说明、remark、note |

- 结束页留空时按单页处理。
- 页码支持 `12`、`12.0`、`第12页` 等写法，脚本提取其中的整数。
- CSV 编码自动识别：UTF-8（含 BOM）、GB18030、GBK 依次尝试。

### 组证据

证据编号写成 `5` 与 `5-1`、`5-2` 时，`5` 被识别为组证据的父级：

- 父级**不生成独立文件**，仅在目录中作为归组行（页码可留空）；
- `5-1`、`5-2` 各自切分，文件名前缀为 `05-1`、`05-2`；
- 合并卷宗时，父级作为一级书签，子证据作为其下级书签。

若清单中没有父级 `5`，子证据仍会切分，但会给出 `ORPHAN_CHILD` 警告。

## 三种页码模式

案卷的"卷宗第 X 页"与 PDF 的物理页序经常不一致：封面、目录、隔页往往不编入卷宗页码。三种模式按优先级依次为锚点表、固定偏移、物理页序。

### 1. 物理页序（默认）

清单页码即 PDF 物理页序，不加任何偏移。适用于清单页码直接从 PDF 阅读器读取的场景。

```bash
python evidence_pdf_splitter.py -p 卷宗.pdf -l 清单.xlsx
```

### 2. 固定偏移

整本卷宗的偏移一致时使用。

```bash
python evidence_pdf_splitter.py -p 卷宗.pdf -l 清单.xlsx --offset 2
```

物理页 = 卷宗页 + 2。前置 2 页为封面与目录。偏移可为负值。

### 3. 分段偏移（锚点表）

卷宗中间插入了未编号页、或分册合并后偏移发生变化时使用。每行一个锚点，格式为 `卷宗页码,物理页码`，支持 `#` 注释：

```csv
# 卷宗页码, 物理页码
1,3
10,14
```

含义：卷宗第 1 页对应物理第 3 页；卷宗第 10 页之前又插入了 2 页未编号材料，故卷宗第 10 页对应物理第 14 页。

```bash
python evidence_pdf_splitter.py -p 卷宗.pdf -l 清单.xlsx --map-file 锚点.csv
```

校验规则：卷宗页与物理页均须严格递增，且物理页增量不得小于卷宗页增量（否则两页会映射到同一物理页）。卷宗页码早于首个锚点时直接报错，不做外推。

## 输出

```
输出/
├── 证据文件/
│   ├── 01_借条_卷宗p3.pdf
│   ├── 02_银行转账凭证_卷宗p4-6.pdf
│   ├── 03_建设工程施工合同_卷宗p7-14.pdf
│   ├── 04_竣工验收报告_卷宗p15-16.pdf
│   ├── 05-1_催告函_卷宗p17-18.pdf
│   └── 05-2_回函_卷宗p19-20.pdf
├── 合并卷宗_带书签.pdf      # --mode merged/both 时生成，按页序合并并加二级书签
├── 证据目录.xlsx            # 带表头样式、冻结首行、A4 横向打印设置
├── 证据目录.md              # 同内容 Markdown 副本，便于粘贴或版本管理
└── 校验报告.txt             # 校验明细 + 源文件 SHA256
```

文件命名规则：`编号_证据名称_页码前缀.pdf`。编号按证据编号补零至两位（`5-1` → `05-1`）；名称中的 `\ / : * ? " < > |` 等非法字符替换为下划线，并限制长度；页码取清单页码区间。

目录列可通过修改源码顶部的 `OUTPUT_COLUMNS` 调整（字段名、表头、列宽），`CENTER_COLUMNS` 控制居中列。

## 校验规则

校验在写盘之前完成。存在 error 级问题时直接终止，不生成任何文件。

| 代码 | 级别 | 含义 |
|---|---|---|
| `MISSING_EID` | 错误 | 缺少证据编号 |
| `MISSING_NAME` | 错误 | 缺少证据名称 |
| `NO_PAGE` | 错误 | 非组证据缺少页码 |
| `REVERSED` | 错误 | 起始页大于结束页 |
| `MAP_FAILED` | 错误 | 页码换算失败（如早于首个锚点） |
| `OUT_OF_RANGE` | 错误 | 换算后超出源 PDF 总页数 |
| `DUP_EID` | 错误 | 证据编号重复 |
| `OVERLAP` | 错误 | 两条证据的页码区间重叠（`--allow-overlap` 可降为警告） |
| `UNCOVERED` | 警告 | 存在未被任何证据覆盖的页，可能是漏列或空白页 |
| `GROUP_PAGE_IGNORED` | 警告 | 组证据父级填了页码，但按子证据切分，父级页码不生效 |
| `ORPHAN_CHILD` | 警告 | 存在子证据但清单中没有对应父级 |

重叠检测按物理页排序后进行，与清单的书写顺序无关。

退出码：`0` 成功；`1` 校验失败（或运行后源文件哈希变化）；`2` 参数、文件或依赖错误；`130` 用户中断。

## 常见报错与处理

| 现象 | 原因与处理 |
|---|---|
| `未能在清单前 20 行中找到必要的表头列` | 列名不在别名表内。改用标准列名，或修改源码中的 `COLUMN_ALIASES` |
| `证据 X 换算后超出源文件总页数` | 偏移量填错，或页码本应是卷宗页却按物理页填写。先用 `--dry-run` 核对 |
| `页码区间重叠` | 清单录入错误，常见于相邻证据的边界页重复计入。按提示核对两条记录 |
| `存在 N 项未被任何证据覆盖` | 检查是否为空白页、隔页，或漏列的证据 |
| `写入被拒绝` | 输出目录中的同名 PDF 正被阅读器占用，关闭后重试 |
| Excel 中 `5` 与 `5-1` 被识别为日期或数字 | 将证据编号列设为"文本"格式后重新保存 |

## 已知限制

- 不做 OCR，不解析证据内容，不自动识别证据标题。
- 不处理加密 PDF：若源文件设置了口令，需先解密。
- 不生成封面页、分隔页、页码标签等装订要素，目录首行标题由 `--title` 提供。
- 输出目录中同名文件会被覆盖（以保证重复运行结果一致），因此不同案件应使用不同的 `-o` 目录。
- 仅支持单个源 PDF；分册卷宗需先合并，或用锚点表配合分册的页序。
